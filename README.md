# ☕ Learn Java

> **From Java fundamentals to modern Java — learn, understand, and code it step by step.**

A comprehensive, beginner-friendly journey through **Core Java**, covering everything from programming fundamentals and Object-Oriented Programming to Generics, Collections, advanced Java APIs, Multithreading & Concurrency, and modern features introduced in Java 8, Java 17, and Java 21.

This repository focuses not only on **how to use Java**, but also on understanding the concepts through practical examples, hands-on coding, and problem-solving.
